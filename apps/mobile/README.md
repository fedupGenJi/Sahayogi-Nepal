# Mobile (Person 1)
android/ios folders are generated by `../../scripts/setup.sh`
(`flutter create --platforms=android,ios . --org np.sahayogi --project-name sahayogi_mobile`).
**One person runs it once and commits android/ and ios/ so everyone shares identical platform files.**

The home screen language switch saves English/Nepali preference on device. The public request, assistance, and donation forms include a bilingual AI suggestion flow. For local Supabase, set `OPENAI_API_KEY` (and optionally `FORM_ASSISTANT_MODEL`) in the function environment; for hosted Supabase, set those Edge Function secrets and deploy `assist-form`. Apply the new `auth_attempts` throttle migration before deploying the function. AI suggestions only populate the existing fields after the requester reviews them; the map location and submit action remain manual.
